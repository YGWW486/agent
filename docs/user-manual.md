# Agentic Engineering Console — 使用指南

> 版本 0.1.0 | 2026-05-13

---

## 这是什么

一个本地运行的 AI 编码控制台。你提交需求规格，AI Agent 自动完成代码编写、自检、审查，最后人工审批合入。

**流程**：提交需求 → Planner 拆解任务 → Coder 写代码 → Reviewer 审查 → 你审批 → 查看代码 Diff

---

## 启动

双击 `portable.exe`，应用打开后**后端自动启动**，Sidebar 底部状态灯变绿即可使用。

如果超过 10 秒还是红灯，检查 `.env` 文件里的 `ANTHROPIC_API_KEY` 是否正确填写。

---

## 首页

启动后看到首页，显示：
- 后端状态卡（端口、运行时间）
- "新建工作流" 按钮
- 最近提交的工作流列表

---

## 提交工作流

1. 点击首页的 **新建工作流** 按钮（或 Sidebar → 工作流 → 新建）
2. 在 **需求规格** 文本框输入你要做什么（可输入最多 50000 字符）

   ```
   例如：创建一个 FastAPI 用户注册接口，支持邮箱+密码注册，
   输入验证，密码哈希存储，返回 JWT token
   ```

3. **上下文** 文本框可选，用于补充项目技术栈、文件路径等
4. 点击 **启动工作流**，页面自动跳转到执行详情页

---

## 监控执行

工作流详情页显示一条垂直时间线，4 个节点从上到下逐一执行：

| 节点 | 做什么 | 看什么 |
|------|--------|--------|
| **Planner** | 拆解需求为任务 DAG | 展开看任务列表（每任务 ≤15 分钟） |
| **Coder** | 逐个任务生成代码 | 展开看 Diff 对比 + 自检结果表 |
| **Reviewer** | 审查代码并附带测试 | 展开看审查结论（通过/拒绝）+ 测试用例 |
| **Merge** | 合入最终代码 | 状态确认 |

节点颜色含义：

| 颜色 | 状态 |
|------|------|
| 橙红 | Planner · 任务拆解 |
| 青绿 | Coder · 代码生成 |
| 蓝色 | Reviewer · 代码审查 |
| 紫色 | Merge · 合入审批 |
| 灰色圆点 | 等待中 |
| 脉冲彩色 | 运行中 |
| 绿色实心 | 成功 |
| 红色实心 | 失败 |
| 橙色三角 | 挂起等待人工介入 |

顶部显示 **实时 / 已断开** 状态指示，确认 SSE 推送连接正常。

---

## 人工审批

当 Reviewer 完成审查后，时间线上弹出审批面板：

1. 查看 Coder 任务摘要和 Reviewer 结论
2. **通过**：点击 "通过 · 合入"，代码直接合入
3. **拒绝**：在文本框填写拒绝原因，点击 "拒绝 · 打回修改"，Coder 收到反馈重新修改

拒绝原因要写具体，例如 "User 模型缺少 email 格式校验"。

---

## 查看代码

**Diff 对比**：Coder 节点展开后，Monaco 编辑器中左右分栏显示代码变更。

**测试用例**：Reviewer 节点展开后，可看到附带的可运行测试，点击 📋 按钮复制代码。

---

## 知识索引

如果你运行过 `/graphify` 生成了 `graph.json`，可以加载到索引中供 Agent 查询：

1. 点击 Sidebar → **索引**
2. 点击 **选择 graph.json**，在文件对话框中选择 `graphify-out/graph.json`
3. 点击 **重建索引**
4. 统计卡片显示节点数、边数、已索引文件数

Planner 和 Coder 节点会自动从索引中获取项目上下文（文件列表、符号摘要）。

## 设置

Sidebar → **设置**：

**API 密钥** 标签：
- Anthropic API Key：你的 API 密钥（密码框，本地存储）
- LangSmith API Key：可选，用于全链路追踪调试

**高级设置** 标签：
- 后端端口：默认 8000，修改后需重启
- 最大修订轮次：Coder 被驳回后最多重试次数
- 工作流超时：单个工作流最长执行时间（秒）
- 单任务 Token 上限：每个任务最多消耗的 Token
- 每日 Token 预算：达到上限后停止执行

## 故障处理

| 症状 | 解决 |
|------|------|
| 后端一直红灯 | 检查 `.env` 的 `ANTHROPIC_API_KEY` 是否有效；终端查看 `[python:err]` 日志 |
| SSE 断开 | 自动重连（指数退避），无需手动操作 |
| 工作流挂起（橙色） | Coder 失败超限或 Planner 不合理 → 修改需求描述后重新提交 |
| 审批后无响应 | 点击审批面板按钮后等待后端响应，前端会自动收起面板 |

---

## 注意事项

- 所有数据存储在本地，API Key 加密保存在本地文件
- 后端仅监听 `127.0.0.1`，外部网络无法访问
- 工作流执行结果写入项目目录，不会自动提交到 Git
- 关闭应用时会自动停止后端 Python 进程
